# Activity 3: Social Media Infographics & Project Documentation

## 📝 Description

Developed a project proposal for VeriFact Health Hub, a technology-based platform that addresses online misinformation about Tirzepatide, along with an educational infographic highlighting health facts, safety concerns, and ways to verify online health information.

## 💡 What Have I Learned?

Through this activity, I learned how to organize project ideas into a proposal and present important information through infographics. I also realized the importance of researching and verifying information before sharing it, especially when it involves health-related topics. This activity helped me improve my skills in information gathering, content organization, and visual communication.
