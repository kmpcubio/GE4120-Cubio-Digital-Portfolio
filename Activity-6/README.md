# Activity 6: Making a Website

## 📝 Description

Created a website for my business, Kustom, using AI-powered website-building tools to establish an online presence and showcase the business.

## 💡 What Have I Learned?

Through this activity, I learned how AI-powered tools can make website creation faster and easier, even without advanced technical skills. I was surprised by how quickly a website could be generated using simple instructions. I also realized the importance of reviewing the website's content, images, and product details to ensure that everything is accurate and properly represents the business.
