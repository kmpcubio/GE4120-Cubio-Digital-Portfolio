# Activity 7: Resume Generating

## 📝 Description

Generated resumes using ChatGPT and Claude AI to compare their outputs, formats, and content in creating a professional resume.

## 💡 What Have I Learned?

Through this activity, I learned how different AI tools can help create professional resumes more efficiently. I noticed that ChatGPT and Claude AI can produce different formats and suggestions even when given similar instructions. I also realized that AI-generated resumes still need to be reviewed and personalized to ensure that the information is accurate and reflects my actual skills and qualifications.
